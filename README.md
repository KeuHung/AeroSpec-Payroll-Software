# AeroSpec Payroll Software

A standalone, browser-based payroll workflow application for AeroSpec.

## Run locally

Download or clone this repository and open **index.html** in Chrome, Edge or another modern desktop browser. No build step or server is needed.

## Features

The application's main sections include Employee Information, Employee Directory, Employee Pay, Payroll Service Summary, Weekly Employee History, Settings & Data Backups, and Export Payroll Workbook.

## Important privacy and accuracy notes

Keep this repository **private**. Do not commit employee records, timesheets, pay rates, payroll exports, passwords or other personal/company data.

The application uses browser local storage for some state. Do not rely on a browser profile as your only data backup, and do not use a shared or public computer for real payroll records.

Review generated calculations and exports carefully before using them for payment processing; this is a local tool, not a connection to your payroll provider.

## Files

- `index.html` — complete HTML/CSS/JavaScript app.
- `.gitignore` — excludes common payroll exports, backups and confidential data folders.

## Development

Edit `index.html`, test the workflow in a browser, and commit your changes.
